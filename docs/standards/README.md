# Standards

Canonical cross-project standards for repositories maintained by `couimet`. They are version-controlled here in `couimet/idea-garden` and change through pull requests.

| Standard            | Path                                                    | Summary                                    | Status    |
| ------------------- | ------------------------------------------------------- | ------------------------------------------ | --------- |
| README Badge Policy | [`docs/standards/readme-badges.md`](./readme-badges.md) | When and how to display badges on READMEs. | Published |

Future standards follow the same process: propose a change through a pull request in `couimet/idea-garden`, describe the affected repository types and migration impact, and add a row to this index when merged.
